---
title: ChartScatter
description: Configure XY scatter charts with iso-lines, highlight bands, and small multiples.
---

`ChartScatter` manifests describe XY scattergrams:
two numeric value axes, one point per data row, points colored by series,
selective collision-free labels, optional highlight bands, and hyperbolic
iso-lines `x·y = k` for a third derived measure.

## Minimal definition

The smallest well-formed `ChartScatter` sets the required `dataset`, `x` and `y`
plus the fields a readable scattergram needs: an axis `label` and `unit` on both
axes (values are drawn as delivered, so the unit is the only magnitude cue) and a
`chartTitle` carrying the message.

```yaml
apiVersion: bino.bi/v1alpha1
kind: ChartScatter
metadata:
  name: product_portfolio
spec:
  dataset: products
  chartTitle: "Product portfolio"
  x:
    measure: ac1
    label: "Margin"
    unit: "% of net sales"
  y:
    measure: ac2
    label: "Net sales"
    unit: "mUSD"
```

All attributes are listed in the [Attribute Reference](#attribute-reference) below.

Both axis mappings also accept the short form `x: ac1` instead of the object
shown above - see [Measure tokens](#measure-tokens).

## Measure tokens

The `x` and `y` mappings accept either a bare **measure token** or an object
whose `measure` property is a token:

- **Scenario slots**: `ac1`-`ac4`, `pp1`-`pp4`, `fc1`-`fc4`, `pl1`-`pl4` -
  the row columns of the dataset.
- **Variance tokens**: `d<base>_<delta>` (absolute) or `dr<base>_<delta>`
  (relative), e.g. `dac1_pp1` (AC minus PY) or `drac1_pl1` (AC vs. plan in
  percent). An optional `_pos`/`_neg`/`_neu`/`_op`/`_opinv` sentiment suffix is accepted
  and ignored on axes.

An axis with a relative variance (a `dr` token such as `drac1_pp1`) is a
percent axis. Its ticks print percent (`20%`), and `min`, `max`, `refLine`,
`highlight.from` and `highlight.to` of that axis are read in percent: write
`min: -40`, not `min: -0.4`. The ticks already carry the percent sign, so
such an axis needs no `unit: "%"`.

All plain scenario measures across `x` and `y` must share one scenario
family (e.g. don't mix `ac1` with `pp2`); the family selects the mark
treatment through the rule set. Variance tokens don't count toward the
family.

A bare string is shorthand for the object form: `x: ac1` equals
`x: { measure: ac1 }`.

## Data mapping

One dataset row is one point - aggregate in the DataSet SQL; duplicate
point identities keep the first row and raise a warning. Values are drawn
as delivered (no auto-SI scaling).

- `level` picks the hierarchy column that identifies a point (`auto` uses
  the deepest populated level of `rowGroup` → `category` → `subCategory`).
- `seriesLevel` picks the level whose values become the color series; it
  must be strictly above the point level. `none` renders a single series.
- `facet` splits the plot into small-multiple panels on a level above the
  series level.

Iso-lines need axes that do not start below 0. An axis that starts at 0 is
fine with template engine v1.0.0-next.75 or newer, before that both axes had
to start above 0. On an axis below 0 the lines are left out. `bino lint`
reports a typed `min` below 0 with
[`chart-scatter-iso-axis-below-zero`](/appendix/lint-rules/#chart-scatter-iso-axis-below-zero),
and `bino build --layout-state` reports the warning of the engine as
`layout-component-warning`, also when the negative value comes from the data.

The value of a line is `x·y·factor`. Without `factor` it is the plain
product, which is seldom the number you want to print: a margin of 25 (%)
times net sales of 20 (mUSD) is 500, not a gross profit of 5 mUSD. Set
`factor: 0.01` for this case, or `factor: 0.001` for lines in millions over
axes in units and thousands. `values` and `highlight.from` are then written
in the unit of the lines.

## Fields

- `dataset` - required dataset name, inline definition, or array of either.
- `x`, `y` - required axis measure mappings (token or object with
  `measure`, `label`, `unit`, `min`, `max`, `step`, `decimals`, `titlePosition`, `refLine`, and `highlight` with
  `from`/`to`; an open end runs to the domain edge).
- `iso` - optional iso-line configuration (`values`, `label`, `unit`, `factor`,
  `highlight.from` shades the region where `x·y·factor >= from`).
- `level`, `seriesLevel` - point identity and series grouping levels.
- `facet` - small-multiple configuration (`level` required, `columns`).
- `labels` - point labels: `points` is `auto` (up to `max` collision-free
  candidates), `all`, `none`, or an explicit list of point names, where an
  entry can be `{ name, side }` to fix the side of the label; `values`
  adds the measure value. Defaults: `points: auto`, `values: false`,
  `max: 12`.
- `legend` - series legend (`show` defaults to `true`, `position` to
  `right`, `align` to `start`).
- `aspect` - plot aspect ratio `"w:h"` (default `16:9`); XY charts have no
  data-driven height.
- `limit` - max points per facet panel, keeping the first rows in dataset
  order; `0` means unlimited.
- `filter` - optional AlaSQL WHERE fragment.
- `chartTitle` - optional title.
- `scale` - proportional font scaling, same semantics as the other charts
  (`none`, `auto`, or a fixed factor).
- `selectedStyle` - optional name of a [`ComponentStyle`](/reference/component-style/) to apply; merged over the `_system` and `_default` styles.
- `ruleset` - optional name of a [`RuleSet`](/reference/ruleset/) to apply, or `inherited-closest` / `inherited-page` to inherit the surrounding layout's rule set.

## Example: Basic scattergram

```yaml
---
apiVersion: bino.bi/v1alpha1
kind: ChartScatter
metadata:
  name: product_portfolio
spec:
  dataset: products
  chartTitle: "Product portfolio"
  x:
    measure: ac1
    label: "Margin"
    unit: "% of net sales"
    min: 0
    max: 40
  y:
    measure: ac2
    label: "Net sales"
    unit: "mUSD"
    highlight: { from: 30 }
  labels:
    points: auto
    max: 12
```

## Example: Iso-lines with highlight

```yaml
---
apiVersion: bino.bi/v1alpha1
kind: ChartScatter
metadata:
  name: gross_profit_scatter
spec:
  dataset: products
  x: { measure: ac1, label: "Margin", unit: "%", min: 0, max: 40 }
  y: { measure: ac2, label: "Net sales", unit: "mUSD", min: 0 }
  iso:
    values: [1, 2, 3]
    label: "Gross profit"
    unit: "mUSD"
    factor: 0.01 # the margin is in percent
    highlight: { from: 3 }
  labels:
    points: [RX-4, { name: RX-2000, side: n }]
```

## Example: Variance scatter with small multiples

```yaml
---
apiVersion: bino.bi/v1alpha1
kind: ChartScatter
metadata:
  name: growth_vs_plan
spec:
  dataset: business_units
  x: { measure: drac1_pp1, label: "Growth", refLine: 0 }
  y: { measure: drac1_pl1, label: "Plan deviation", refLine: 0 }
  level: subcategory
  seriesLevel: category
  facet:
    level: rowgroup
    columns: 4
```

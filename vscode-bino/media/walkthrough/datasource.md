# Add a DataSource

A DataSource tells bino where the data comes from: a CSV, Excel or Parquet file, or a database.

- **From a file:** right-click a `.csv`, `.xlsx` or `.parquet` file in the Explorer and pick **New DataSource from File...**.
- **From a database:** click **Open the DataSource wizard**.

The wizard shows the columns and some rows, then writes the YAML for you.
